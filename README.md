# Ride Mapper

A phone-friendly website for Disneyland Resort days with young kids.

- Live wait times from [ThemeParks.wiki](https://themeparks.wiki), refreshed every 5 minutes
- "Go next" ranks rides by walk time from your location plus the current wait
- Park switch: Disneyland, California Adventure, or both
- Height check for each kid, Rider Switch hints, and a "Skip scary rides" toggle
- Alerts when popular rides are shorter than usual, before parades and shows, and for Lightning Lane return times
- Trip calendar with park hours
- Kid-friendly restaurant picks from family reviews
- Step-by-step ride guide with a link to POV videos

Hosted on GitHub Pages from `main` (see `.github/workflows/pages.yml`). No build step: plain HTML, CSS and JavaScript.

Not affiliated with Disney.
